BYDMAX · 产品介绍
专为比亚迪 DiLink 车机打造的智能用车伴侣：实时车况、行程与充电统计、语音控车、自动化于一体，数据本地留存，安装即用。

一、软件简介
BYDMAX 是一款运行在比亚迪 DiLink 智能车机上的第三方增强应用。它直接读取车辆总线数据，把电量、续航、能耗、行程、充电等核心信息以清晰的可视化面板呈现，并提供语音助手、自动化规则、投影投屏、悬浮窗等能力，帮助车主更懂车、更省电、更省心。所有用车数据保存在本机，支持配置备份与一键恢复，并内置应用内自动更新。

三、主要功能介绍
1. 首页 · 实时车况
大字号 SOC 电量环 + 预估续航里程，一眼掌握还能跑多远。
今日里程 / 今日能耗 / 实时功率，车况动态实时刷新。
车况洞察：能耗同比趋势（优于/弱于上周），用车表现心中有数。
电池健康芯片：SoH 健康度、电池温度、车载电源电压、电压差、绝缘电阻，异常早发现。
TRIP 1 / TRIP 2 两段里程独立统计，满足不同周期对比。
周期统计（日 / 周 / 月 / 年 / 全部）+ 中式年月日时间节点，四张统计卡展示里程、能耗、百公里电耗、费用；里程卡同时显示累计里程与累计行程数。
照片框置顶固定、下方内容上下滑动，信息一屏一屏看不完就滑。
2. 行程 · 用车统计
行程按日分组，列表展示起止时间、时长、公里、SOC 变化、kWh、百公里电耗。
顶部按时间段汇总里程 / 能耗 / 电耗 / 费用。
点按任意行程查看详情：距离、时长、平均电耗、费用、起止 SOC 等。
兼容纯电与 DM-i 混动（混动额外显示油耗列）。
3. 充电 · 充电管理
充电记录列表：充电量、起止 SOC、费用、家充 / 快充类型一目了然。
统计卡片：充电次数、累计费用。
全生命周期（系统数据）：累计充入电量、等效循环、BMS 里程、SoH 健康度。
支持手动补录充电记录、编辑与删除。
4. 投影 · DiLink 投屏
导航与助手画面直接投射到仪表盘，HUD 与语音助手也能看到导航。
「出厂 / 扩展」两种投影模式可选，切换不影响车机原有设置（可随时恢复出厂值）。
5. 悬浮窗 · 随时看车况
前台服务悬浮窗，实时显示电量、续航等关键信息，切到任何界面都能看见。
6. 设置 · 个性化与备份
多语言（俄 / 英 / 简中）、主题、字体。
电价设置（家充 / 快充单价），费用统计更准确。
TTS 语音音色选择、充电接口类型。
配置备份 / 恢复：行程与充电历史、设置、自动化、地点一键备份到「下载」目录，换机 / 重装后一键恢复（含恢复后自检）。
日志录制，便于排查问题。
7. 更新 · 应用内自动升级
启动后自动检查新版本，提示「可更新至 vX」，一键下载安装。
更新只提示版本与安装，不展示冗长更新说明；正式版经同一签名密钥签发，直接覆盖升级，数据不丢。
